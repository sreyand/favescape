# Visual direction

`tastemap-reference.png` is the user's approved starting direction, created during the project brainstorm. The product now uses the working name Favescape.

Preserve the reference's warm cream, cobalt, tomato accents, large italic display type, thin ink outlines, record-sleeve geometry, and a map that occupies most of the workspace. Apply the retro influence to typography and composition; do not turn the interface into beverage packaging.

The implementation adds the later agreed product features: a persistent local player, personal mood/enjoyment ratings, a mood map, measured sound/metric views, and TastePlay routes. These make the first app different from the original genre-map-only concept while retaining its visual character.

Display text uses self-hosted Fraunces italic and interface text uses self-hosted DM Sans. Demo sleeves are original SVG artwork. Demo music and personal ratings are explicitly identified as examples rather than actual commercial song analysis.

The user's V1 feedback calls for a more minimalist presentation. Keep the retro type and color, give the map space, and use a single quiet toolbar. Default song panels show artwork and essentials; ratings, metrics, map editing, and advanced playback appear on demand. Omit decorative slogans, repeated explanations, duplicate actions, and dense rows of buttons.
